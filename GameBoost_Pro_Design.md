# GameBoost Pro - 游戏手机性能优化应用

## 交互设计稿 v1.0

---

## 1. 设计规范

### 1.1 设计变量配置
| 参数 | 值 | 说明 |
|------|-----|------|
| DESIGN_VARIANCE | 8 | 非对称布局，强调视觉层次 |
| MOTION_INTENSITY | 6 | 流畅的物理动画，适度微交互 |
| VISUAL_DENSITY | 4 | 适中的信息密度，功能分区清晰 |

### 1.2 色彩系统

## 2. 信息架构

### 2.1 页面结构
```
├── 首页 (Dashboard)
│   ├── 当前游戏状态卡片
│   ├── 快速调节面板
│   ├── 性能监控实时数据
│   └── 预设配置文件快捷入口
│
├── 性能引擎 (Performance Engine)
│   ├── CPU 频率控制
│   ├── GPU 频率控制
│   ├── 温控阈值设置
│   └── 综合性能模式
│
├── 显示优化 (Display Optimization)
│   ├── 刷新率锁定
│   ├── 触控参数调节
│   └── 显示增强控制
│
├── 系统调度 (System Scheduler)
│   ├── 内存优先级配置
│   ├── 后台管理策略
│   └── 充电性能模式
│
├── 配置中心 (Config Center)
│   ├── 我的配置
│   ├── MI 社区广场
│   ├── 扫码分享
│   └── 配置导入
│
└── 设置 (Settings)
    ├── 应用偏好
    ├── 通知管理
    └── 关于
```

### 2.2 导航模式
采用底部 Tab 栏导航，5 个主要入口：
- 首页 (home)
- 性能 (zap)
- 显示 (monitor)
- 调度 (cpu)
- 我的 (user)

## 13. 性能监控数据模型

### 13.1 实时监控数据结构

```typescript
interface PerformanceMonitor {
  // CPU 信息
  cpu: {
    bigCore: {
      frequency: number;      // MHz
      usage: number;         // 百分比 0-100
      temperature: number;   // 摄氏度
    };
    smallCore: {
      frequency: number;
      usage: number;
      temperature: number;
    };
  };

  // GPU 信息
  gpu: {
    frequency: number;       // MHz
    usage: number;           // 百分比 0-100
    temperature: number;     // 摄氏度
    voltage: number;         // mV
  };

  // 内存信息
  memory: {
    total: number;           // MB
    available: number;       // MB
    gameUsage: number;       // MB
    backgroundUsage: number; // MB
  };

  // 显示信息
  display: {
    refreshRate: number;      // Hz
    currentFps: number;      // FPS
    brightness: number;      // 百分比
    touchSampleRate: number; // Hz
  };

  // 电池信息
  battery: {
    level: number;           // 百分比
    status: 'charging' | 'discharging' | 'full';
    temperature: number;     // 摄氏度
  };

  // 游戏信息
  game: {
    name: string;
    packageName: string;
    isActive: boolean;
    playingTime: number;      // 秒
  };
}
```
